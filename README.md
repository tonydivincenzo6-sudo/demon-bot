# Turbo Power

Geode-Mod fuer Geometry Dash 2.2081: Level laufen so schnell, wie der PC es schafft (bis 100x), ohne einzufrieren,
und unter Windows mit voller CPU-Leistung. Arbeitet mit dem Demon Bot (`tony.demon-bot`) zusammen.

Gebaut wird per GitHub Actions (`.github/workflows/build.yml`); die fertige `.geode`-Datei liegt im Artefakt "Build Output".
